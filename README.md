# SAFE-VIEW

> **AI 기반 사각지대 위험 감지 시스템**  
> 2026 캡스톤 디자인

도로변에 주차된 차량 때문에 보이지 않는 골목, 또는 노상 공영주차장처럼 시야가 제한된 환경에서 발생하는 보행자-차량 충돌 위험을 미리 감지하기 위한 시스템이다. 기존에 설치되어 있는 CCTV 영상을 그대로 받아와 AI 모델이 사람과 차량을 실시간으로 추적하고, 사용자가 지정한 위험 구역 안에서 둘이 마주칠 가능성이 발생하면 즉시 경고를 띄운다.

별도의 하드웨어 설치 없이 기존 카메라 인프라만으로 운영할 수 있도록 설계하는 것이 목표였다.

<br>

##  어떤 일을 하는가

이 시스템이 처리하는 흐름은 단순하다. 카메라에서 들어온 영상을 한 프레임씩 분석해서, 화면 안에 사람과 차량이 있는지 확인한다. 그리고 그 위치가 사용자가 미리 설정해둔 **'위험 구역'** 안인지 밖인지 따져본다. 안에서 둘이 동시에 발견되면 사고 가능성이 있다고 판단하고, 그 순간을 자동으로 녹화해 따로 보관한다.

### 위험 판정 기준

| 화면 안의 상황 | 위치 | 시스템 반응 |
| :--- | :---: | :--- |
| 사람과 차량이 모두 있음 | 위험 구역 **내부** |  위험 |
| 사람과 차량이 모두 있음 | 위험 구역 외부 | 정상 |
| 사람만 있음 | 어디든 | 정상 |
| 차량만 있음 | 어디든 | 정상 |

운영자는 웹 브라우저에서 실시간 영상을 확인할 수 있고, 과거에 발생했던 위험 이벤트들을 시간 순으로 다시 돌려볼 수 있다.

<br>

##  구성

**백엔드**는 Python으로 작성된 FastAPI 서버가 담당한다. 영상 처리와 AI 추론이 모두 이쪽에서 이루어지며, 결과는 HTTP 스트림 형태로 프론트엔드에 전달된다. **프론트엔드**는 React로 만들어졌고, 운영자가 마주하는 거의 모든 화면 — 실시간 모니터링, 이벤트 목록, 위험 구역 설정 화면 — 이 이 안에 들어있다.

객체 인식은 Ultralytics의 **YOLOv8 nano** 모델을 사용한다. 더 크고 정확한 모델도 있지만, 실시간 처리 속도를 우선시해서 가장 가벼운 버전을 선택했다. 영상은 **OpenCV**로 RTSP 스트림을 받아오며, 위험 구간을 따로 저장할 때는 **ffmpeg**을 파이프 방식으로 연결해 H.264 코덱으로 인코딩한다.

외부에서 접속이 필요할 때는 **Cloudflare Tunnel**을 통해 공인 IP나 포트 개방 없이 외부에 노출시킬 수 있다.

<br>

##  폴더 구성

```
safeviewV2/
├── config.py
├── requirements.txt
│
├── backend/
│   ├── main.py            # FastAPI 진입점, 스트리밍 라우터

│   ├── danger_logic.py    # 위험 판정 규칙
│   ├── event_saver.py     # 이벤트 클립 저장 (ffmpeg)
│   └── roi_manager.py     # 위험 구역 좌표 관리
│
├── core/
│   └── video_source.py    # RTSP 연결, 재시도 루프
│
├── frontend/
│   └── src/components/
│       ├── Dashboard.jsx
│       ├── EventList.jsx
│       └── ROIEditor.jsx
│
└── server/                # MediaMTX 설정 파일
```

> `saved_events/`, `roi_configs/`, `logs/` 디렉터리는 실행 시점에 자동으로 생성된다.

##  실행 방법

### 백엔드

```bash
git clone https://github.com/originalgodkimchi/safeviewV2.git
cd safeviewV2

python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

### 프론트엔드 (새 터미널)

```bash
cd frontend
npm install
npm start
```

| 서버 | 주소 |
| :--- | :--- |
| 백엔드 | `http://localhost:8000` |
| 프론트엔드 | `http://localhost:3000` |

### CCTV 연결 (RTSP)

카메라를 연결하려면 `config.py`에 RTSP 주소를 추가하면 된다.

```python
RTSP_PRESETS = [
    {
        "name": "주차장 입구",
        "url": "rtsp://계정:비밀번호@IP주소:554/Streaming/Channels/102"
    }
]
```

##  AI 도구 활용에 관하여

개발 과정에서 **Claude(Anthropic)** 와 **Cursor AI**를 활용했다. 어떤 부분을 AI의 도움을 받았고 어떤 부분은 직접 했는지 솔직하게 적어둔다.

### AI의 도움을 받은 부분

AI는 주로 반복적이거나 시간이 오래 걸리는 코드 작성에 활용했다. FastAPI 서버의 기본 구조나 React 화면의 뼈대를 잡는 작업, 공식 문서를 한참 뒤져야 알 수 있는 ffmpeg 연동 부분, 그리고 에러가 발생했을 때 원인을 분석하고 해결 방향을 잡는 데 도움을 받았다.

- **Cursor AI** — 코드를 작성하는 중간중간 자동완성이나 부분 수정을 받는 용도
- **Claude** — 전체 구조를 설계하거나 긴 코드를 한 번에 작성할 때, 또는 라이선스 검토처럼 여러 정보를 종합해서 판단해야 하는 작업

git 커밋이나 폴더 정리 같은 단순 반복 작업을 자동화하는 스크립트도 AI의 도움을 받아 만들었다.

### 직접 진행한 부분

직접 결정하고 수행한 작업도 분명히 있다. 어떤 기능이 필요한지 정리하는 단계, 시스템 전체의 동작 흐름을 어떻게 구성할지, 위험 구역 판정 기준을 어떻게 정의할지 같은 핵심적인 부분은 모두 직접 판단했다. 자택 CCTV에 실제로 연결해서 시스템이 제대로 동작하는지 확인하는 과정, AI가 작성한 코드가 실제 환경에서 의도대로 돌아가는지 검토하고 수정하는 일, 팀원 및 지도교수님과의 피드백을 반영하는 작업도 직접 진행했다.

사용한 라이브러리의 동작 원리나 선택 이유는 개발하면서 함께 공부했다. 코드를 단순히 가져다 붙이는 데 그치지 않고, **왜 이렇게 동작하는지 이해하려는 노력을 계속 병행했다.**

##  라이선스

캡스톤 졸업작품이라는 학술 목적으로 제작되었고, 사용한 모든 오픈소스의 라이선스 조건은 검토하여 준수하였다. 상세한 분석은 별도의 「**오픈소스 활용 보고서**」에 정리되어 있다.

| 라이브러리 | 라이선스 |
| :--- | :--- |
| YOLOv8 (Ultralytics) | `AGPL-3.0` |
| FastAPI | `MIT` |
| React | `MIT` |
| OpenCV | `Apache 2.0` |
| MediaMTX | `MIT` |
| Cloudflare Tunnel | `Apache 2.0` |
| NumPy, Pillow | `BSD` |
| ffmpeg | `LGPL-2.1+` |

>  향후 상업적인 용도로 활용하려면 YOLOv8의 **AGPL-3.0** 조건 때문에 소스 공개 의무가 따라온다. 이 경우 다른 모델로 교체하거나 Ultralytics가 별도로 제공하는 엔터프라이즈 라이선스를 구매하는 방법을 고려해야 한다.
